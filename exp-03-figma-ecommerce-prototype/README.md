# Experiment 3 – E-Commerce Mobile App Prototype for Stakeholder Review (Figma)

**Tool:** Figma  **CO:** CO1

## Scenario
Stakeholders disagree on the mobile-app UI (navigation style, amount of promotion on the home screen, look & feel).
A shared clickable prototype lets everyone react to the same artefact and lets the team record decisions.

## Procedure
1. Create a Figma file *E-Commerce App*. Build frames: **Home (Option A)**, **Home (Option B)**, **Product**, **Cart**, **Checkout**
   (see `wireframes.svg`).
2. Build two variants of the home screen on one page (*Option A* bottom tabs, *Option B* card feed with hamburger menu).
3. **Prototype** tab → connect Home → Product → Cart → Checkout for both variants.
4. **Share** → set *Anyone with the link can **comment***; send the link to all stakeholders.
5. Collect comments using Figma's comment tool (**C**), reply to each one and resolve when agreed.
6. Record the outcome in `stakeholder-feedback.csv` and iterate until every stakeholder row is **Approved**.

## Deliverables
* Figma prototype link: `PASTE_LINK_HERE`
* `stakeholder-feedback.csv` – concerns, response, decision, status
* Screenshots: frames + comment threads

## Outcome of the sample review
Hybrid design: **bottom-tab navigation** (fast checkout), one **promotional banner** above the fold, reusable components.

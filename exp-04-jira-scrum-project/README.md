# Experiment 4 – Scrum Project in Jira

**Tool:** Jira  **CO:** CO2 (Figma part CO1)

## Aim
Create a Scrum project, build a backlog of ≥5 items, prioritise it, plan a 1-week sprint, start it, and show the sprint board at
the start and end.

## Procedure
1. Jira → **Create project → Scrum** → name *Library Auth* (key `LIB`).
2. **Backlog** → **Create issue** for each row of `backlog.csv` (or import: *Settings → System → External system import → CSV*).
3. Set **Story points** (estimate) and **Priority**; drag issues to order the backlog (highest on top).
4. **Create sprint** → name *Sprint 1*, goal *Users can register and log in*.
5. Drag the top five items into *Sprint 1* → **Start sprint** → Duration **1 week** → Start.
6. Open **Active sprints** and **screenshot the board (start)**.
7. Move cards To Do → In Progress → Done during the week; open **Reports → Burndown chart**.
8. **Complete sprint** (unfinished issues move to the next sprint); **screenshot the board (end)**.

## Files
* `backlog.csv` – import-ready backlog with sprint assignment
* `sprint-plan.md` – prioritisation, sprint goal, sample start/end boards and burndown
* `screenshots/` – `01-backlog.png`, `02-sprint-start-board.png`, `03-sprint-end-board.png`

## Viva points
Roles (PO, Scrum Master, Team), artefacts (product backlog, sprint backlog, increment), events (planning, daily scrum, review, retrospective).
